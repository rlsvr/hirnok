# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| >= 0.1  | :white_check_mark: |

## Reporting a Vulnerability

If you discover a security issue or vulnerability within `hirnok`, please do not report it publicly through GitHub issues or discussions.

Instead, please send an email to **fuxi21@gmail.com** with details of the vulnerability, steps to reproduce, and any relevant logs or proofs of concept.

You will receive an acknowledgment within 48 hours, followed by coordinated disclosure and remediation.
